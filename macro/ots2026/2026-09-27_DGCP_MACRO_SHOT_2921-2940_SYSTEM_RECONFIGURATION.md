### DGCP™ Macro Shot #2921: System Reconfiguration

System reconfiguration describes changes in how components, resources, capacity, infrastructure, networks, institutions, and functions are arranged within a system.

Reconfiguration can alter relationships without removing the underlying system itself.

Changes can occur through redistribution, replacement, reconnection, separation, consolidation, or functional reassignment.

System reconfiguration remains observable.

### DGCP™ Macro Shot #2940: System Reconfiguration Framework

System reconfiguration connects components, resources, capacity, infrastructure, flows, networks, dependencies, suppliers, production, geography, time, technology, information, institutions, functions, and interfaces.

Reconfiguration can redistribute system activity without requiring the disappearance of the wider system or its underlying functions.

Cross-system reconfiguration connects structural change across operational domains while reconfiguration sequences describe how changes unfold across connected components over time.

Together these relationships reveal how system architecture changes through redistribution, replacement, reconnection, reassignment, and structural rearrangement.
