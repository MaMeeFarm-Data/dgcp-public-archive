### DGCP™ Macro Shot #2901: Network Effects

Network effects describe how changes in nodes, links, participants, connectivity, flows, or network scale alter the operation of connected systems.

Networks can support the movement of materials, energy, information, transactions, people, services, and other forms of activity.

Changes within one part of a network can modify conditions experienced elsewhere through connected relationships.

### DGCP™ Macro Shot #2902: Node Effects

Node effects occur when the characteristics or activity of individual nodes influence wider network operations.

Nodes can function as origins, destinations, transfer points, processors, storage locations, gateways, platforms, or control points.

Differences in node capacity, connectivity, function, and utilization alter network relationships.

### DGCP™ Macro Shot #2903: Link Effects

Link effects occur when the characteristics of connections between nodes influence network activity.

### DGCP™ Macro Shot #2904: Connectivity Effects

Connectivity effects occur when changes in the number, arrangement, or quality of connections alter how network components interact.

Connectivity determines which nodes and activities can interact directly or indirectly.

### DGCP™ Macro Shot #2920: Network Effects Framework

Network effects connect nodes, links, connectivity, density, reach, scale, participation, flows, routing, hubs, gateways, clusters, and interoperability.

Amplification and dampening describe how network structures influence the transmission of activity and change across connected pathways.

Cross-system network effects connect different operational domains while network reconfiguration describes how the architecture of connectivity changes over time.

Together these relationships reveal how connected structures shape the distribution, transmission, reach, and interaction of activity across interconnected systems.
