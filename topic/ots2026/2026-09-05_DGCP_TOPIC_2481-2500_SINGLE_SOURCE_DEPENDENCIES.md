### DGCP™ Topic #2481: Single-Source Dependencies

Single-source dependencies occur when a system, organization, network, or activity relies on one primary source for an input, capability, service, route, technology, or function.

A single source can exist at different layers including resources, suppliers, facilities, infrastructure, geographic regions, technologies, and institutional systems.

Dependency becomes structurally identifiable when continued operation connects to a source with limited equivalent alternatives within the observed system.

Single-source dependencies remain structurally observable.

I log single-source dependencies.

### DGCP™ Topic #2482: Single-Source Resource Dependency

Single-source resource dependency occurs when a production or operating system relies predominantly on one source of a required natural resource or primary material.

The source can be associated with a particular deposit, production area, supplier, country, or extraction system.

Downstream activities connect to the resource through processing, transportation, storage, trade, and commercial structures.

Single-source resource dependency remains structurally observable.

I log single-source resource dependency.

### DGCP™ Topic #2499: Layered Single-Source Dependency

Layered single-source dependency occurs when multiple single-source relationships exist within the same operating or production system.

A system can simultaneously depend on one material source, one specialized supplier, one processing facility, one transport route, one technology, or one supporting network.

These dependencies can occupy different layers while remaining connected through the same end-to-end operating structure.
